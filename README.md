从网易云音乐、QQ音乐、酷狗音乐（都需要客户端）自动抓取当前播放歌曲的歌词，并以逐字显示、字符颤抖、3D透视、发光等仿月计风格渲染在桌面上，不会干扰鼠标操作。

## 使用说明
1. 打开音乐播放器并播放歌曲
2. 运行本程序，控制面板自动弹出
3. 点击 **从播放器获取当前歌词** 或勾选 **自动切换歌曲**
4. 点击 **开始**，歌词悬浮窗开始渲染

- 要编辑源码，需要下载 PyQt5 requests psutil pywin32
